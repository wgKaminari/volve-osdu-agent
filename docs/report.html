  • The agent reads report prose far better than one big prompt: 14 of 16 depths and elevations from report text correct, against 4 for the single-prompt baseline, with the same small local model.
  • Nothing invented reaches the output. Every report fact must quote its page verbatim and pass type, range and wellbore checks; 9 agent proposals and 29 baseline proposals were rejected and flagged instead of emitted.
  • Every conflict was routed to a human: all 19 known and injected conflicts (logs deeper than the well, swapped coordinates, plan well paths, contradictory headers) were flagged, with no false flags.
  • The data itself has problems the ground truth does not show: mixed coordinate datums, a sidetrack's TD recorded on its parent, and report-vs-registry disagreements (section 6).

1. What was measured

Three systems, one pipeline

All three share parsing, record building (Equinor's osdu-python-models) and validation; they differ only in the judgement steps: which wellbore it is, facts from report prose, curve mapping.

  • rules: regex on report text + a static curve dictionary, no LLM
  • llm_only: one prompt per wellbore, no retrieval, lookup or retries
  • agent: LangGraph graph with focused prompts, page retrieval, reference-list lookup and up to 2 retries with the validator's error message

Independent ground truth

NPD wellbore headers (11 of 13 wellbores; technical sidetracks are not registered) and Equinor's well picks. Gold is read only by evaluation code; a test records every file a run opens and fails if gold is among them.

  • Recoverable values (stated in some input) are scored for accuracy
  • Not recoverable values must be left empty (abstention)
  • Disputed values (inputs disagree with NPD) are reported, never scored

9. Limitations

  • Small n. 13 wellbores, header gold for 11, some fields with 1-7 values: intervals are wide by necessity.
  • No held-out development set. The rules baseline and the semantic grounding checks were shaped after seeing these bundles; both runs are reported.
  • Provisional curve labels. 0/269 owner-reviewed; curve mapping is the weakest area for a 4B model (many rock-physics curves left unmapped rather than guessed).
  • Assumptions. Coordinate datum is assumed and flagged; ACL and legal tags are placeholders; no real OSDU instance is called.
  • Scope. LAS, PDF text and well paths only: DLIS files, Word reports, formation tops and image-only report pages are not read.
